## About

I'm **B V S Aneesh** — an AI engineer and full-stack developer based in Visakhapatnam, India. I build intelligent systems and full-stack applications: from AI-powered platforms to data-rich products, with a core focus on engineering depth and real-world impact.

I love working at the edge of what's possible — RAG systems, multi-agent architectures, and intelligent products grounded in real data. I'm just as comfortable modelling a database and wiring up APIs as I am crafting the interface on top of them. My stack of choice is TypeScript/Next.js on the frontend and Python/FastAPI or NestJS on the backend, deployed cloud-native on Vercel and Docker.

Currently, I'm the founder of **Dinomem** — a Postgres-native memory layer and SDK for AI agents, featuring hybrid semantic + BM25 + entity-graph retrieval, Gemini re-ranking, CRDT conflict resolution, TTL, and BYOK encryption — shipping as `@dinomem/sdk` (TypeScript) and `dinomem-py` (Python). I've competed in 8 hackathons across India building autonomous agents, AI finance platforms, and agentic SaaS products.

**Open To:** Full-time SWE / AI Engineer roles · ML engineering internships · AI product collaborations · Open source contributions

## Featured Projects

<details>
  <summary><b>🧠 Dinomem — Postgres-Native Memory Layer for AI Agents</b>b></summary>summary>

<br/>

Dinomem is a production-grade memory infrastructure for AI agents. It provides hybrid retrieval combining semantic vector search, BM25 full-text matching, and an entity-relationship graph, with Gemini-powered re-ranking on top. The system ships as two first-class SDKs — `@dinomem/sdk` for TypeScript and `dinomem-py` for Python — making it drop-in compatible with any LLM stack. Features include CRDT conflict resolution for concurrent agent writes, TTL-based memory expiry, and BYOK (Bring Your Own Key) encryption for enterprise deployments. Currently in active development — public release coming soon.

<br/>

    <summary><b>⚙️ CodeWeaver — Autonomous AI SRE Incident Response Agent</b></summary>

    <br/>

    CodeWeaver is an autonomous SRE agent that closes the entire incident response loop without human intervention. When a production alert fires via webhook, CodeWeaver reads application logs from shared Docker volumes, invokes a Groq-hosted LLM to diagnose the root cause, generates a Python remediation script, executes it against live service APIs, and validates that the system has returned to a healthy state — all within seconds. Ships with an integrated `chaos-app` for continuous chaos engineering and resilience validation. Built and demoed at the AI Buildathon by CrossStack.

    <br/>

    <details>
    <summary><b>🔧 AutoHeal-CI — Autonomous CI/CD Pipeline Healing Agent</b></summary>

    <br/>

    AutoHeal-CI is a multi-provider autonomous agent that monitors CI/CD pipelines, identifies failing tests and broken code, generates minimal JSON patch diffs via LLM inference, validates each fix in an isolated sandbox, and pushes successful patches back to the repository without human input. Supports Groq (Llama 3), OpenAI (GPT-4), DeepSeek, and Gemini as provider backends. Features a real-time React dashboard with live streaming logs, exponential-backoff git retry logic, and fuzzy patch matching. Built and placed at RIFT '26 Hackathon, PW Institute of Innovation, Bangalore.
